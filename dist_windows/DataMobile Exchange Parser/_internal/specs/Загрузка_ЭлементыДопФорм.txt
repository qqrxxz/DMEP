Описание параметров
Параметр	Описание
КоличествоСтрокВФайле	Общее количество строк в файле, не считая первую
РежимЗагрузкиФайла	Режим загрузки: «+» - добавить к текущим элементам. «-» - удалить таблицу элементов и добавить новые.
1. ПорядковыйНомер	Номер текущей строки элемента
2. Операция	Режим загрузки: «+» - добавить элемент. «-» - удалить элемент.
3. Наименование	Наименование
4. ТипДанных	0 - Текст 1 - Число 2 - Дата 3 - Ссылочный тип 4 - Булево
5. ИдентификаторДопФормы	Идентификатор дополнительной формы
6. ИдентификаторСправочника	Идентификатор типа значения дополнительной формы
