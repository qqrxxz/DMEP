Описание параметров
Параметр	Описание
КоличествоСтрокВФайле	Общее количество строк в файле, не считая первую
РежимЗагрузкиФайла	Режим загрузки:
«+» - добавить к текущим связям.
«-» - удалить таблицу связей и добавить новые.
1. ПорядковыйНомер	Номер текущей строки связи
2. Операция	Режим загрузки:
«+» - добавить связь.
«-» - удалить связь.
3. ИдентификаторДополнительнойФормы	Идентификатор дополнительной формы
4. КодШаблона	Код шаблона
5. ПорядковыйНомер	Порядковый номер (для сортировки)
(Не используется)
6. ОбязательноКЗаполнению	0 – нет.
1 – да.
7. Тип	0 – строка.
1 – шапка.
8. ПорядковыйНомер	Порядковый номер (для сортировки)
9. ПроверкаПоЗаданию	Да/Нет
10. РежимВвода	0 - По умолчанию
1 - Вручную
2 - Автоматически
11. ТипОперации	0 - подбор
1 - размещение
