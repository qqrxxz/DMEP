DataMobile Exchange Parser — portable-версия для Windows x64

Установка не требуется.

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Не переносите один EXE отдельно: рядом находится папка _internal,
   необходимая для работы программы.
3. Запустите файл «DataMobile Exchange Parser.exe».

Поддерживаемые входные файлы: .dm, .dmU и .dmu.
Приложение работает локально и не требует подключения к интернету.
